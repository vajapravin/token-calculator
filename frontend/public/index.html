FAQ

Does this calculator upload my text?
Counting and visualization run entirely in your browser. Pressing "Invoke model" sends the text to your own TokenCount backend, which forwards it to the selected provider using a server-side key and returns the response with billed token usage.
Are the token counts exact?
The live count is a local pattern-based estimate (typically within ±10–15%). For the exact number, press "Invoke model" — the response shows the provider-billed input and output tokens, which is the ground truth for that model.
How many tokens are in 1,000 words?
English prose averages roughly 1.3–1.5 tokens per word, so about 1,300–1,500 tokens. Code, JSON, and non-English text usually cost more tokens per word.
Why do different sites give different counts?
Two reasons: some tools estimate instead of running a real tokenizer, and different model families use different vocabularies — the same text genuinely has a different token count on GPT, Claude, and Gemini.
